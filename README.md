# 撲克學習站

個人撲克學習站（中文介面）。V1 聚焦可互動的翻前 13×13 範圍設計器；筆記／策略記錄之後再加。

- **不包含**真實金流或多人對戰
- **技術**：Next.js（App Router）+ TypeScript + Tailwind CSS
- **儲存**：瀏覽器 `localStorage`

## 本機開發

需要 Node.js 18+（建議 20/22）與 npm。

```bash
cd D:\Poker
npm install
npm run dev
```

瀏覽器開啟 [http://localhost:3000](http://localhost:3000)。

## V1 功能

- 13×13 起手牌矩陣（點選／拖曳上色）
- 行動圖例：棄牌／跟注／加注／全下／混合
- 名稱、位置、備註欄位
- 本機儲存與載入列表
